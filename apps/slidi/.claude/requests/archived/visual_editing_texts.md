# Feature Request: Visual Editing of Texts

## Description
Implement the ability for users to visually edit text directly within the presentation slides. Instead of just editing the source code or using sidebars, users should be able to click on text elements in the canvas and modify them in place.

## Requirements
- Changes should be reflected in the underlying presentation data model.
- [x] Click-to-edit implemented with direct source code replacement.
- [ ] Basic formatting (bold/italic) — *Pending future refinement.*
