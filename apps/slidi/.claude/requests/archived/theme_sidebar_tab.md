# Feature Request: Theme Sidebar Tab

## Description
Optimize the theme selection process by consolidating it into a dedicated side panel.

## Requirements
- Add a "Theme" tab next to the "Source" tab.
- When clicked, it should open a sidebar on the left side of the screen.
- Provide a clear interface for selecting and previewing themes.
