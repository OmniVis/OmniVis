# Feature Request: Better Settings Tab

## Description
Reorganize the settings interface into a more scalable and organized layout using internal navigation.

## Requirements
- Implement a sidebar navigation on the left of the settings frame.
- **General Tab:** For basic application settings.
- **Graphical/UI Tab:** For visual and display-related settings.
- **API Keys Tab:** Move the current API key configuration into this new sub-tab for better consolidation.
