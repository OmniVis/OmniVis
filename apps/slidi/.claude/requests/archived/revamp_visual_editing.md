# Feature Request: Revamp Visual Editing

## Description
Improve the existing visual editing experience by making it more intuitive and responsive.

## Requirements
- **Visibility:** Make the visual editing button significantly more prominent and easier to find.
- **Real-time Sync:** The visual editing should update the text inside the presentation canvas in real-time as the user types.
- **Improved Interaction:** Smoother transitions and feedback when entering/exiting edit mode.
