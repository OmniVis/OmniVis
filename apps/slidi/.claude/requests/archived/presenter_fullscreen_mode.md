# Feature Request: Presenter and Full-Screen Mode

## Description
Provide high-quality presentation capabilities for both the main application and shared links.

## Requirements
- **Full-Screen Mode:** Implement a standard full-screen viewing experience.
- **Presenter Mode:** A special view for the presenter that includes notes, timer, and slide previews (on a separate window or screen).
- **Availability:** Both modes should be available on the normal site and when viewing a shared link.
