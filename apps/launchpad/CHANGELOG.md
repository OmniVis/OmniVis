# Changelog - Launchpad

All notable changes to Launchpad will be documented in this file.

## [Recent] - 2026-05-12

### Added
- **Changelog**: Integrated a filterable changelog with pagination on the main page.
- **Status Page**: Added a central status page for all services.
- **Feedback Form**: Added a dedicated feedback page.
- **Error Pages**: Added custom branded 404 and 50x error pages.
- **WebSocket Proxy**: Added support for Slidi's real-time collaboration backend.

### Fixed
- **Branding**: Improved logo size and header alignment for a more consistent feel.
