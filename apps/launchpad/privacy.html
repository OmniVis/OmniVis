Privacy Policy

Effective Date: May 18, 2026

1. Privacy-by-Design Architecture

OmniVis is built from the ground up as a privacy-first, client-side application. All of your technical diagrams, visual presentations, code edits, and workspace settings compile directly within your local browser. We do not transmit your creative content to any proprietary centralized servers.

2. Bring-Your-Own-Key (BYOK) Data Sovereignty

When using the advanced AI features powered by OpenAI or Anthropic models, your API credentials (keys) are stored strictly within your browser's local sandbox storage (localStorage).

  • Your keys are never transmitted to OmniVis, OmniVis Team, or any secondary analytics servers.
  • API requests are routed directly from your client machine to the respect model providers or via your explicitly configured custom Worker gateway URL.
  • You can reset or clear all saved credentials and local configurations at any time using the "Reset Local Config" button on the Command Center dashboard.

3. Cookies and Local Storage

We do not use trackers, profiling cookies, or ad-targeting integrations. We utilize standard Web Storage (localStorage) solely to preserve your active UI configurations, system themes, active diagram templates, and user-seeded presentations to ensure workspace continuity across page reloads.

4. Third-Party Integrations

OmniVis provides deep linking capabilities and repository synchronization to GitHub and Cloudflare services. These services operate under their respective privacy parameters and developer agreements. We encourage you to review Cloudflare D1 databases and GitHub Pages privacy disclosures if deploying collaborative hubs.

5. Contact Information

For privacy audits, compliance queries, or code repository inquiries, please contact the developer team through our visual command center portal.
